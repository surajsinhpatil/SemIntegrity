# Architecture / methodology decision records

One file per decision that changes or *resolves* something the proposal
underdetermines. Numbered, append-only. A decision that contradicts the
proposal is not recorded here without the researcher's explicit sign-off — it is
raised in [`../OPEN_QUESTIONS.md`](../OPEN_QUESTIONS.md) first.

Status values: `PROPOSED` · `ACCEPTED` · `SUPERSEDED BY ADR-nnnn` · `REJECTED`
